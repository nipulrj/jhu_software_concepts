API reference
=============

Every page here is generated by ``sphinx.ext.autodoc`` from the modules' own
docstrings, so there is one description of each function rather than two that
can drift apart.  Autodoc imports each module to read them, which every module
tolerates with no database running: :mod:`models` builds its Engine on first
use, and nothing else opens a connection until it is asked a question.
