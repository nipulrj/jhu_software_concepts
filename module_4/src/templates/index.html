Pull Data

Pull Data checks Grad Cafe for newly submitted application results and adds any new records to the database. Depending on how much new data is available this may take some time, so it runs in the background — you can keep reading this page while it works. Press Update Analysis once it finishes to recompute the figures below.

Only new entries are added. Anything already stored is recognized by its Grad Cafe result id and refreshed rather than duplicated, and a second pull cannot start while one is already running.
